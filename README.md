🗺️ Current Roadmap
​We are constantly pushing the boundaries of mobile Minecraft performance. Here is what is next:
​[x] Fully functional instance and profile management system
​[x] Out-of-the box 1.21+ support
​[x] Native mrpack / CurseForge zip import
​[x] Overhaul UI to Glassmorphism 2.0 with dynamic backgrounds
​[ ] Implement advanced FPS-boosting compute shader extensions
​[ ] Integrate built-in modpack and texture pack management
​[ ] Patch-on-dlopen for complex mod native libraries
​⚠️ Known Issues
​High-Res Texture Packs: Extremely large texture atlases might experience slight distortion on certain mobile GPUs.
​External Peripherals: Some physical Bluetooth mice may register slower tracking speeds than expected.
​Found a bug? Help us squash it by opening an issue on our bug tracker!
